# Changelog

## 0.1.0 (2026-04-13)

### Added
- Initial release with 5 agency MCP packages
- Shared core library with 9 tools, FTS5 search, HTTP server
- Arbetsmiljoverket (AV): 55 AFS regulations, 504 sections
- Boverket: 137 BFS regulations, 17,029 sections (via open REST API)
- MSB/MCF: 68 MSBFS/MCFFS regulations, 872 sections
- Folkhalsomyndigheten (FoHM): 69 FoHMFS/HSLF-FS regulations, 562 sections
- Stralsakerhetsmyndigheten (SSM): 41 SSMFS regulations, 1,279 sections (PDF extraction)
- CI/CD: matrix build, GHCR, npm publish, ingestion, freshness monitoring
- Security: CodeQL, Semgrep, Trivy, Gitleaks, Scorecard, Dependabot
